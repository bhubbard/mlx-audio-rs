Unified Memory Metal Audio Architecture ⚡

Kokoro-82M TTS

Text & phoneme tokens ➔ Style latent vector ➔ Metal flow matching transformer decoder ➔ 24kHz studio PCM waveform.

Whisper STT

Raw 16kHz PCM audio ➔ Log-mel filterbank tensor ➔ Conv1D audio encoder ➔ Autoregressive text token decoder.

SNAC & Silero VAD

Multi-scale residual vector quantization (12Hz/24Hz/48Hz) and sub-millisecond voice activity gating.

Installation & Usage 🚀

# Install from Cargo
cargo install --git https://github.com/bhubbard/mlx-audio-rs

# 1. Kokoro Text-to-Speech
mlx-audio tts -t "The quick brown fox jumps over the lazy dog." -o audio.wav

# 2. Whisper Speech-to-Text
mlx-audio stt -a interview.wav -m base

# 3. Silero Voice Activity Detection
mlx-audio vad -a meeting.wav --threshold 0.5

# 4. Neural Codec Encode/Decode
mlx-audio codec -i recording.wav -o restored.wav
